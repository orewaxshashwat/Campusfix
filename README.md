# CampusFix AI

**CampusFix AI** is an intelligent campus issue reporting and management platform designed to make educational campuses smarter, safer, and more efficient.

The platform allows students to report campus issues such as broken equipment, water leaks, damaged infrastructure, and Wi-Fi failures. Using AI-powered classification and prioritization, CampusFix AI helps maintenance teams identify urgent problems, detect duplicate reports, and manage resolutions efficiently.

## Key Features

- 🤖 **AI-Powered Issue Classification** — Automatically categorizes reported problems and suggests the responsible department.
- 🚨 **Smart Priority Detection** — Highlights urgent and safety-related issues for faster attention.
- 🔍 **Duplicate Issue Detection** — Identifies similar reports to reduce redundant tickets.
- 📊 **Interactive Dashboard** — Tracks reported issues, priorities, and resolution progress.
- 🗺️ **Campus Issue Mapping** — Visualizes problems across campus locations.
- 🔄 **Issue Tracking** — Allows staff to update issue statuses and monitor progress.

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend and Database: Supabase
- AI Integration: Gemini API or another compatible LLM API
- Data Visualization: Recharts
- Mapping: Leaflet and OpenStreetMap
- Deployment: Vercel

## Goal

To transform traditional campus complaint systems into an intelligent, transparent, and data-driven maintenance platform that improves issue reporting, prioritization, and resolution.

*Built to explore practical applications of AI in smart infrastructure and campus management.*
